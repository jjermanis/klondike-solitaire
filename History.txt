Version 01.01	26 minutes dev	2 minutes AI	4 minutes test		32 minutes

The goal for this game is simple. My wife plays solitaire on her tablet. But the
on-line version have repetitive ads. The base solitaire (Klondike) is in the
public domain. I can just create a version of the game (like my wife likes)
without the ads.
I asked Claude to ask me the question it would have for implementing Klondike
Solitaire. It had eight - all were easy to answer. Claude developed the initial
version after this.
It did well. There a couple defects, some other minor changes, but it is
playable as-is.

Version 02.01	18 minutes dev	1 minute AI	4 minutes test		4 hours 21

This resolves one severe defect. There was a case where there were two aces next to 
each other, visible on the columns. I tapped the first ace. As the animation 
happened to move the first ace, I tapped the second ace. When that first animation 
ended, BOTH aces were not on the columns, but you could only see one ace on the 
foundation.
To address, Claude introduced an animating flag. While something is being animated,
it is set to true. While that flag is set, another move cannot be set: the 
animation needs to finish before making another move. This worked well in testing.

see how it does on tablet.
